Installation

Install LambdaVim after backing up any existing Neovim configuration.

Requirements

  • Neovim ≥ 0.10
  • Git
  • A Nerd Font for icons
  • A terminal with true color support

Backup your existing Neovim configuration

mv ~/.config/nvim ~/.config/nvim.bak

Clone LambdaVim

git clone https://github.com/smit4k/LambdaVim ~/.config/nvim

Launch Neovim

nvim

What happens next

  • lazy.nvim bootstraps automatically from lua/config/lazy.lua
  • Plugins install on first launch
  • The dashboard gives you shortcuts into files, recent buffers, search, config, and Lazy
