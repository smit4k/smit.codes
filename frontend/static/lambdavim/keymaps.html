Keymaps

The repo defines keymaps in a few plugin specs plus the completion engine. Leader is set to space

Normal Mode

Mode Key Action Source
n <leader>e Toggle Neo-tree lua/plugins/neo-tree.lua
n <leader>f Format buffer lua/plugins/conform.lua
n <leader>ug Toggle indent guides lua/plugins/indent-blankline.lua
n <leader>? Show buffer-local keymaps with which-key lua/plugins/which-key.lua
n <Leader>; Pick symbols in the winbar lua/plugins/dropbar.lua
n [; Go to the start of the current context lua/plugins/dropbar.lua
n ]; Select the next context lua/plugins/dropbar.lua
n <leader>xx Toggle diagnostics list lua/plugins/trouble.lua
n <leader>xX Toggle buffer diagnostics lua/plugins/trouble.lua
n <leader>cs Toggle symbols view lua/plugins/trouble.lua
n <leader>cl Toggle LSP definitions and references lua/plugins/trouble.lua
n <leader>xL Toggle location list lua/plugins/trouble.lua
n <leader>xQ Toggle quickfix list lua/plugins/trouble.lua
n <leader>bp Toggle pin on the current buffer lua/plugins/bufferline.lua
n <leader>bP Close non-pinned buffers lua/plugins/bufferline.lua
n <leader>br Close buffers to the right lua/plugins/bufferline.lua
n <leader>bl Close buffers to the left lua/plugins/bufferline.lua
n <S-h> Previous buffer lua/plugins/bufferline.lua
n <S-l> Next buffer lua/plugins/bufferline.lua
n [b Previous buffer lua/plugins/bufferline.lua
n ]b Next buffer lua/plugins/bufferline.lua
n [B Move buffer left lua/plugins/bufferline.lua
n ]B Move buffer right lua/plugins/bufferline.lua
