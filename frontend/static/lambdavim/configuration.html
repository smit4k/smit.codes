Configuration

LambdaVim keeps core editor behavior in init.lua and plugin bootstrapping in lua/config/lazy.lua.

Editor Defaults

Setting Value Purpose
mapleader Space Matches the repo's plugin keymaps
tabstop, shiftwidth, softtabstop 4 Uses four-space indentation width
expandtab false Keeps literal tabs instead of spaces
smartindent, autoindent true Provides basic indentation behavior
number, relativenumber true Shows absolute and relative line numbers
signcolumn yes Reserves gutter space for diagnostics and signs
clipboard unnamedplus Uses the system clipboard by default

Window Behavior

init.lua adds a WinEnter autocmd that hides line numbers and the sign column in noice and Telescope windows. That keeps those transient views visually clean while preserving the normal gutter in regular buffers.

Lazy Bootstrap

lua/config/lazy.lua installs lazy.nvim when missing, prepends it to the runtime path, and then loads every plugin spec from lua/plugins. 

require("lazy").setup({
  spec = {
    -- import your plugins
    { import = "plugins" },
  },
  -- automatically check for plugin updates
  checker = { enabled = true },
})
